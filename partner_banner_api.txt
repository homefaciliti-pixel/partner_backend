1. GET ACTIVE BANNERS FOR DASHBOARD
----------------------------------------------------------------------
Endpoint: GET /api/partner/dashboard
Headers:
  Authorization: Bearer <PARTNER_TOKEN>
Description: Retrieves active banners (as absolute URLs) along with booking stats, earnings, and approval status.

----------------------------------------------------------------------
2. BANNERS MANAGEMENT API (ADMIN/GLOBAL)
----------------------------------------------------------------------

2.1 GET ALL BANNERS
-------------------
Endpoint: GET /api/settings/banners
Description: Retrieves a list of all banners (active and inactive) in the system.
Response Example (Status 200 OK):
{
  "success": true,
  "data": [
    {
      "id": 29,
      "title": "Save Video Banner",
      "image": "save.mp4",
      "status": true,
      "category": "",
      "badge": "",
      "subtitle": "",
      "buttonText": "Watch Video"
    }
  ]
}

2.2 UPLOAD/ADD NEW BANNER
-------------------------
Endpoint: POST /api/settings/banners
Request Format: multipart/form-data
Description: Adds a new banner with an image/video file.
Request Fields:
- title (String, Required) - e.g., "Save Video Banner"
- status (Boolean/String, Optional) - "true" or 1
- image (File, Required) - The banner image or video file
- category (String, Optional)
- badge (String, Optional)
- subtitle (String, Optional)
- buttonText (String, Optional)
Response Example (Status 201 Created):
{
  "success": true,
  "data": {
    "id": 29,
    "title": "Save Video Banner",
    "image": "save.mp4",
    "status": true,
    "category": "",
    "badge": "",
    "subtitle": "",
    "buttonText": "Watch Video"
  }
}
